# Free demo deploy: Neon + Render + Vercel

A public demo for $0, with no credit card anywhere. The production-shaped setup
for your own server is [deploy.md](deploy.md); this is the free-tier version of it.

| Piece | Host | Runs |
|---|---|---|
| Postgres + pgvector | Neon (free) | the database |
| Backend | Render (free web service) | Redis, migrations, Celery worker + beat, API: one container, [Dockerfile.render](../backend/Dockerfile.render) |
| Frontend | Vercel (Hobby) | the Next.js app |

What the free tier costs you:
- **Render sleeps after 15 minutes idle.** The first request after that takes about a minute to wake the container.
- **Voice answers are off.** Whisper does not fit in 512 MB alongside everything else.
- **Uploaded résumé files don't survive a restart.** Their text is already in the database, so nothing in the app needs them.

---

## 1. Neon: collect the connection details

In the Neon dashboard, open **Connect**. **Turn "Connection pooling" off.**
The pooled host (the one containing `-pooler`) is PgBouncer in transaction
mode, which breaks asyncpg. The string then looks like this:

```
postgresql://neondb_owner:AbC123xyz@ep-cool-name-123456.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
             └── USER ──┘ └ PASSWORD ┘ └──────────────── HOST ──────────────────────┘ └ DB ─┘
```

Keep this tab open. You need these four values in step 2. Note the region too
(`ap-southeast-1` above is Singapore).

## 2. Render: create the backend

1. Render dashboard → **New** → **Blueprint** → pick the `InterviewIQ` repo.
   Render reads [render.yaml](../render.yaml).
   - If your Neon region is **not** Singapore, first change `region:` in
     `render.yaml` to the nearest of `oregon`, `ohio`, `virginia`, `frankfurt`
     or `singapore`, and push the change. The region can't be changed later.
2. Render asks for the values marked `sync: false`:

   | Key | Value |
   |---|---|
   | `POSTGRES_HOST` | the Neon host, **without** `-pooler` |
   | `POSTGRES_USER` | e.g. `neondb_owner` |
   | `POSTGRES_PASSWORD` | from Neon |
   | `POSTGRES_DB` | e.g. `neondb` |
   | `GEMINI_API_KEYS` | your Gemini key(s), comma-separated |
   | `CORS_ORIGINS` | leave as `http://localhost:3000` for now; set it in step 4 |

   `SECRET_KEY` is generated by Render. Everything else is already set in the file.
3. **Apply.** The first build takes several minutes. The log ends with
   `alembic` upgrading the schema, `celery@... ready`, and `Uvicorn running`.
4. Copy the service URL, e.g. `https://interviewiq-api.onrender.com`, and check
   `https://interviewiq-api.onrender.com/api/v1/health` in a browser.

## 3. Vercel: the frontend

**Add New** → **Project** → import `InterviewIQ`:
- **Root Directory:** `frontend`
- **Environment Variable:** `NEXT_PUBLIC_API_URL` = `https://interviewiq-api.onrender.com/api/v1`

Deploy, then copy the site URL, e.g. `https://interviewiq.vercel.app`.

`NEXT_PUBLIC_API_URL` is baked in at build time. If you change it, redeploy.

## 4. Connect the two

Render → the service → **Environment** → set `CORS_ORIGINS` to the Vercel URL
(exactly as the browser shows it, no trailing slash) → **Save**. Render redeploys.

Open the Vercel site, register, and run one interview end to end.

## 5. Optional: a recruiter account

Render's free tier has no shell, so run the admin CLI **from your own PC against
Neon**. Your environment variables override `.env`:

```bash
cd backend
POSTGRES_HOST=ep-...aws.neon.tech POSTGRES_USER=neondb_owner POSTGRES_PASSWORD=... \
POSTGRES_DB=neondb POSTGRES_SSLMODE=require POSTGRES_PORT=5432 \
  .venv/Scripts/python -m app.cli create-recruiter demo-recruiter@example.com
```

## Troubleshooting

| Symptom | Cause |
|---|---|
| Browser console: "blocked by CORS policy" | `CORS_ORIGINS` doesn't exactly match the Vercel URL. |
| Render log: `SECRET_KEY must be a random string` | `SECRET_KEY` was removed. Add one of 32+ characters. |
| Render log: `prepared statement ... does not exist` | `POSTGRES_HOST` is the `-pooler` host. |
| Render log: "Ran out of memory" | Check `EMBEDDING_THREADS=1` and that the worker runs the solo pool. Don't switch to `EMBEDDING_PROVIDER=hash` while RAG is on: the KB holds 384-wide BGE vectors and retrieval breaks. See [deploy.md](deploy.md#roll-back). |
| Questions never show sources | The KB isn't seeded on Neon. Run `ingest-kb` then `check-rag` against it ([deploy.md](deploy.md)). |
| Interview stuck on "Scoring your answers" | Check the Render log for Gemini 429/503 errors: free quota or model overload. |
| First page load spins for about a minute | The service was asleep. Expected on the free tier. |
